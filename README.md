## 📖 Overview

**CampCon** is a TypeScript web application for camp organization and coordination.

## ✨ Features

- Camp planning workflows
- Responsive UI
- Firebase-ready


## 🛠 Tech Stack

TypeScript, Vite, Firebase.

## 🚀 Getting Started

```bash
git clone <repo-url>
cd <repo>
npm install
npm run dev
```

> Open the dev server URL printed in your terminal.
